## About

[PicoGym](https://play.picoctf.org) is the practice platform for PicoCTF, a beginner-friendly Capture The Flag competition developed by Carnegie Mellon University. It provides a large archive of challenges spanning multiple cybersecurity domains, designed to build practical skills through hands-on problem solving.

## Categories

| Category | Description |
|---|---|
| **Binary Exploitation** | Buffer overflows, format strings, memory corruption |
| **Cryptography** | Classical ciphers, RSA, hashing, encoding schemes |
| **Forensics** | File analysis, steganography, memory and packet forensics |
| **General Skills** | Linux, bash scripting, command-line tools |
| **Misc** | Miscellaneous challenges spanning multiple domains |
| **Reverse Engineering** | Disassembly, decompilation, binary analysis |
| **Web Exploitation** | SQL injection, XSS, authentication bypass, SSRF |
